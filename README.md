# Claude Code plugin Top 5 (weekly)

`claude-top5.json` is refreshed once a week (Monday 06:00 KST) by GitHub Actions. Videos are hand-picked and not updated automatically.

- Ranking: install counts on the official directory https://claude.com/plugins
- Fields: `rank`, `name`, `slug`, `installs`, `desc` (two short Korean lines), `url`, `install` (`/plugin install <slug>@claude-plugins-official`)
- Read it from `https://raw.githubusercontent.com/<owner>/claude-plugins-top5/main/claude-top5.json`
